# TxtToHtml

## Description
This script converts a text file with links into a simple HTML page and opens it in Chrome Incognito mode.

## Requirements
- Python 3.x
- Google Chrome
- `requests` module (install with `pip install requests`)

## Usage
1. Create a `TxtToHtml.txt` file with links and descriptions:
   ```
   Section Name
   https://example.com Description
   ```
2. Run the script:
   
   Just run the file
   
   or
   ```sh
   python TxtToHtml.pyw
   ```
4. The generated HTML file will open in Chrome Incognito mode.
